O objetivo deste projeto foi construir uma Unidade Lógica e Aritmética(ULA)
de 4 bits com oito operações distintas,tendo como obrigatoriedade as operações
de soma e subtração em complemento a dois e checar também se houve
alguma flag(carry,negative,zero e overflow) ativada em uma placa FPGA
(Spartan3A/3AN).Para tal prática,utilizamos a linguagem Very High-Speed
Integrated Circuits(VHDL) e o software Xilinx ISE como ferramentas para
desenvolver a ULA.
